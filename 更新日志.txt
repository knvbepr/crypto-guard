==============================================
             加密卫士 更新日志
==============================================

按发布时间排列，最新版本在最上面。

----------------------------------------------
v1.7  2026-10-04
----------------------------------------------
· Android 版与 Windows 版同步新增：
  - 「随机」密码按钮（14 位，自动填入并明示）
  - 文件列表改为右侧复选框勾选（不再高亮选中行），
    每行之间加分隔线，更直观
  - 解密多个文件时先列出结果再保存：
    ·「保存勾选」逐个保存所选原文件（不打包压缩包）
    ·「全部保存」才打包为 ZIP，重名自动改名
  - 解密后可预览：图片、文本，
    无法识别的文件按 HEX 十六进制预览
  - 音频 / 视频预览：
    · Android：内置播放，带进度条、
      播放/暂停、正计时与倒计时
    · Windows：解密到系统临时文件夹后
      用电脑默认播放器打开
· Windows 版新增高清 DPI 支持
  （Per-Monitor v2，界面随系统缩放不模糊）
· Windows 版默认选中「加密」
· Windows 版图标重绘为 98 风格像素画
  （32×32 像素格近邻放大，内置 16~256 六种尺寸）
· Android 版图标去掉渐变（造型不变，纯色）
· Windows 版修复：
  - 解密结果列表为空
  - 列表勾选框无法点击
  - 预览窗口崩溃、图片被灰块遮挡
  - 视频渲染异常（改用系统播放器）
· 网页版本次无改动

----------------------------------------------

  - 兼容旧版 Safari 的文件读取方式与页面样式
· 回归测试全部通过：
  Windows 互通 16 项 / 安卓互通 19 项 / Safari 兜底 25 项

v1.1  2026-10-04
----------------------------------------------
· 网页版界面重做为 Material Design 1 风格
  （靛蓝主色、粉色点缀、波纹点击效果）
· 密码直接写入加密文件名（形如 文件名__pwd_密码.enc），

  可逐个保存或打包成 ZIP
· 图片 / 视频 / 音频 / 文本解密后可在线预览
· 全部图标改为矢量图标
· 新增拖拽添加、随机密码、密码显示切换
